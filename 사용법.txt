JY Tools (JY Launcher + JY Explorer) 사용법
==========================================

[처음 한 번만]
1) 이 zip 을 원하는 폴더에 풉니다. (한글/공백이 있는 폴더도 괜찮습니다)
2) Python 이 설치돼 있어야 합니다. (3.10 이상, 3.13 에서 테스트)
   - 없으면 https://www.python.org/downloads/ 에서 설치하고,
     설치 첫 화면의 "Add python.exe to PATH" 를 꼭 체크하세요.
   - 확인: 명령 프롬프트에서  python --version
3) SETUP_first_time.bat 을 더블클릭합니다.
   (필요한 프로그램 PySide6, pywin32 를 자동 설치합니다 = pip install -r requirements.txt)
   직접 하려면 이 폴더에서:   python -m pip install -r requirements.txt

[실행]
- run_explorer.bat  : JY Explorer (탐색기)
- run_launcher.bat  : JY Launcher (런처, 단축키 Ctrl+Alt+L)
  (창 없이 트레이에서만 시작하려면 bat 파일 이름 뒤에 --background 를 붙여 명령 프롬프트에서 실행)

[런처 사용 팁]
- 카드를 다른 카드 가운데에 끌어다 놓으면 "폴더"로 묶입니다(시작 메뉴 폴더처럼). 폴더 카드 위에 놓으면 그 안으로 들어갑니다.
- 설정 탭 -> "바로가기 만들기": 시작 메뉴 / 바탕화면에 JY Launcher, JY Explorer 바로가기를 만듭니다.
  작업 표시줄 고정은 시작 메뉴에서 바로가기를 우클릭 -> "작업 표시줄에 고정" (Windows 제한으로 직접 해야 함).
- 탐색기에서 파일/폴더 우클릭 -> "런처에 추가" -> 카테고리 목록에서 고릅니다.

[Win+E 로 탐색기 열기]
- JY Explorer 가 켜져 있으면 Win+E 가 Windows 탐색기 대신 JY Explorer 를 열거나 활성화합니다.
- 꺼져 있으면 Win+E 는 원래 Windows 탐색기가 열립니다.
- 항상 동작하게 하려면: JY Explorer 의 [설정] 메뉴 -> "Windows 시작 시 자동 실행 (트레이 상주)" 체크.
  (이 등록은 폴더 위치가 기록되므로 폴더를 옮기면 체크를 껐다 켜세요)

[내 데이터 (북마크, 빠른 이동, 런처 목록, 설정)]
- 위치:  %APPDATA%\JYTools\   (주소창에 붙여넣으면 열립니다)
- 다른 PC 로 옮기려면 그 폴더를 통째로 복사해서 새 PC 의 같은 위치에 넣으세요.
  (안에 저장된 폴더 경로가 새 PC 에 없으면 빨간색으로 표시됩니다)
- 이 zip 에는 내 데이터가 들어 있지 않습니다. 새로 시작하면 빈 상태에서 시작합니다.
- 폴더 하나로만 들고 다니고 싶다면: 이 폴더에 이름이 portable.txt 인 빈 파일을 만드세요.
  그러면 데이터가 이 폴더 안의 data 폴더에 저장됩니다.

[수정하려면]
- VS Code 등으로 이 폴더를 엽니다. 구조/기능/주의사항은 "런쳐탐색기진행상황.md" 에 정리돼 있습니다.
- 파일: JYExplorer.py(탐색기) JYLauncher.py(런처) jycommon.py(공용) fileops.py(복사/이동 엔진)
        shellmenu.py(Windows 우클릭 메뉴) fonts\(폰트) installer\(설치 프로그램 초안, 미완성)
- 수정 후 그냥 다시 실행하면 반영됩니다. (이미 켜져 있으면 트레이 아이콘 우클릭 -> 종료 후 다시 실행)

[문제가 생기면]
- 창이 안 뜨고 바로 꺼진다:  명령 프롬프트에서  python JYExplorer.py  로 실행하면 오류 내용이 보입니다.
- 우클릭 메뉴가 간단한 메뉴로만 나온다:  pywin32 가 없는 것입니다 -> SETUP_first_time.bat 다시 실행.
